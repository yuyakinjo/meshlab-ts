# Security Policy

## Supported Versions

Only the latest published version of `meshlab-ts` receives security fixes.

| Version | Supported |
| ------- | --------- |
| latest  | ✅        |
| older   | ❌        |

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report it privately via GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/yuyakinjo/meshlab-ts/security)
2. Click **"Report a vulnerability"**
3. Fill in the details (affected version, reproduction steps, impact)

You will receive a response as soon as possible. Once the issue is confirmed
and fixed, a security advisory will be published and credit given to the
reporter (unless anonymity is requested).
